A high-performance Verilog implementation of a Hardware-in-the-Loop (HIL) AC power grid signal generator and synchronization engine. Built for Xilinx/AMD FPGAs (target: Basys 3), this project features a Direct Digital Synthesis (DDS) waveform generator with dynamic harmonic injection, voltage sag simulation, phase jitter modeling, and a Second-Order Generalized Integrator (SOGI-PLL) for grid frequency and phase tracking.

* Features
** DDS Signal Generator (~dds_top.v~)
- Synthesizes 60 Hz fundamental grid voltage ($V$) and current ($I$) waveforms at 100 MHz clock frequency.
- Independent, fixed-point Q0.8 scaling for 3^{rd}, 5^{th}, and 7^{th} odd harmonics on both $V$ and $I$ channels.
- Phase-aligned current harmonics representing non-linear load behaviors.
- Real-time Q1.8 voltage sag and amplitude scaling logic.
- LFSR-based pseudo-random phase jitter injection.
** Verification & Tooling Workflow
- Automated simulation runner via ~run_sim.py~ (Icarus Verilog + Surfer / GTKWave).
- Modular testbench structure supporting multi-phase dynamic injection.

* Getting Started
** Prerequisites
- *Simulator:* [[http://iverilog.icarus.com/][Icarus Verilog]] (~iverilog~)
- *Waveform Viewer:* [[https://gitlab.com/surfer-project/surfer][Surfer]] or [[http://gtkwave.sourceforge.net/][GTKWave]]
- *Python:* Python 3.8+
- *FPGA Synthesis (Optional):* AMD Vivado 2020.2+
** Running Simulations

To run the DDS generator simulation and launch the waveform viewer:

#+BEGIN_SRC bash
python3 run_sim.py tb_dds_top
#+END_SRC
