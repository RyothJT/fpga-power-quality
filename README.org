#+AUTHOR: Justin Troth

A high-performance Verilog implementation of a Hardware-in-the-Loop (HIL) AC power grid signal generator, measurement engine, and synchronization system. Built for Xilinx/AMD Artix-7 FPGAs (target: Digilent Basys 3) using Vivado and open-source simulation tools, this project models real-world grid dynamics including voltage sags, phase jitter, dynamic phase offsets, and independent odd harmonic distortion (3^{rd}, 5^{th}, 7^{th}) on both voltage (V) and current (I) channels.

* Architecture & Features

** Digital Signal Generation (~dds_top.sv~)
- *Fundamental Synthesis:* Synthesizes 60 Hz fundamental grid voltage (V) and current (I) waveforms driven by a 100 MHz clock using a 32-bit Direct Digital Synthesizer (DDS) phase accumulator.
- *Dual-Channel Harmonic Engine:* Independent Q0.8 fixed-point scaling for 3^{rd} (180 Hz), 5^{th} (300 Hz), and 7^{th} (420 Hz) odd harmonics across both V and I paths. Current harmonics are phase-aligned with fundamental current to model non-linear load behaviors.
- *Anomaly Modeling:*
  - Real-time Q1.8 voltage sag and amplitude scaling logic (0% to 100% nominal grid voltage).
  - LFSR-based pseudo-random phase jitter injection for micro-flicker simulation.
  - Dynamic fundamental phase offset control between V and I for power factor modeling.

** Signal Conditioning & Sampling
- *XADC Interface:* Integration hook for the Xilinx XADC IP block (~xadc_interface.sv~) to map external analog inputs or internal digital streams into signed 16-bit Q1.15 fixed-point vectors.

** Core Algorithmic Modules
- *SOGI-PLL Engine:* Integrated Frequency-Adaptive SOGI (=sogi_pll_top.sv=) with internal sine/cosine lookup (=sogi_sine_rom=), Park Transformation, and PI loop filtering to track orthogonal $\alpha/\beta$ components, grid phase angle (=theta=), and measured frequency (=freq_out=).
- *Real-Time Power Calculation Engine:* Computes Instantaneous Active Power (P = V \cdot I), Reactive Power (Q), and real-time RMS metrics using fixed-point arithmetic.
- *Harmonic Analysis Engine:* Evaluates Total Harmonic Distortion (THD) across sampled waveforms via Goertzel or FFT filtering (~thd_analyzer.sv~).

** Verification & Tooling Workflow
- Automated simulation runner via ~run_sim.py~ using Icarus Verilog (~iverilog~) and Surfer / GTKWave waveform visualization.
- Multi-phase testbenches with sat-checked math and fixed-point execution.
- Live hardware telemetry using Xilinx Integrated Logic Analyzer (ILA) IP for real-time tracking of internal signals over USB.

* Getting Started

** Prerequisites
- *Simulator:* [[http://iverilog.icarus.com/][Icarus Verilog]] (~iverilog~)
- *Waveform Viewer:* [[https://gitlab.com/surfer-project/surfer][Surfer]] or [[http://gtkwave.sourceforge.net/][GTKWave]]
- *Python:* Python 3.8+
- *FPGA Toolchain:* AMD Vivado 2020.2+ (for Synthesis, Implementation, and ILA debugging)

** Running Simulations

To run the DDS waveform generator simulation and launch the waveform viewer:

#+BEGIN_SRC bash
python3 run_sim.py tb_dds_top
#+END_SRC
